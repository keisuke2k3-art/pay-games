# PAY games 公式サイト

PAY のブラウザゲームの公式サイト一式です。GitHub Pages にそのまま置けます。

## フォルダ構成

```
index.html              トップページ(作品の泡が水面で割れて飛び出す水槽+作品一覧)
games.js                作品台帳。新作はここに1件足すだけで一覧に出る
site.js / site.css      全ページ共通(上部バー・日本語/EN切替・ほかの作品・作品ページの「遊ぶ」帯・フッター)
404.html                アドレスが間違っているときに出るページ
og.png                  トップを共有したときの画像(1200×630)
robots.txt / sitemap.xml  検索エンジン向け(サイトのアドレスは記入済み)
_docs/                  公開されない資料置き場
  README.md             この説明書
  PUBLISH.md            公開の手順と、公開後にやること
  blog-banner.html      Seesaa ブログのサイドバーに貼るバナー
games/
  the-silent-press/     沈黙の輪転機 The Silent Press(注目作)
  160cm/                布1枚で60cm水槽をサイドテーブルだと言い張るゲーム
  fish-match/           フィッシュマッチ
  frogbit-sweeper/      FROGBIT SWEEPER
  project-genesis/      PROJECT GENESIS//One-Shot-Setup
_template/              新作ページのひな形(公開されません)
```

`_template` はフォルダ名が `_` で始まるため、GitHub Pages では公開されません(ひな形置き場として意図的にそうしています)。

## 公開手順

`_docs/PUBLISH.md` を見てください(GitHub の画面だけで公開できます)。

## 新作を追加する手順

1. `_template` フォルダをコピーして `games/` の中に置き、フォルダ名を作品のスラッグにする
   (英小文字・数字・ハイフンのみ。例: `games/arowana-high-jump/`)
2. コピーした `index.html` の「★」を検索して、順番に書き換える
   - `<body data-game="★slug">` はフォルダ名と同じにする
   - itch.io 埋め込みの `00000` は作品ID(作品の編集画面URL `itch.io/game/edit/1234567` の数字)
   - 色は `:root` の5色を変えるだけで全体が切り替わる
3. `games.js` の配列の**先頭**に1件追加する(下の例をコピー)。無料なら `price: { ja: "無料", en: "Free" }`、遊ぶ目安は `tags` に書く
4. 公開後は `sitemap.xml` に新しいページの `<url>` を1行足す

```js
  {
    slug: "arowana-high-jump",                 // フォルダ名と同じ
    itch: "https://pay-k.itch.io/xxxx",
    itchId: 1234567,
    released: "2026-10-01",
    status: { ja: "公開中", en: "Released" },
    title: { ja: "アロワナ・ハイジャンプ選手権", en: "Arowana High Jump Championship" },
    tagline: { ja: "キャッチコピー", en: "Catchphrase" },
    genre: { ja: "物理アクション", en: "Physics action" },
    short: { ja: "アロワナ・ハイジャンプ", en: "Arowana High Jump" },   // 泡の下に出す短い名前
    cover: "https://img.itch.zone/……/original/……png",
    accent: "#E85D3A",                          // カバー画像が読めないときのアイコンの色
    price: { ja: "無料", en: "Free" },
    tags: [{ ja: "1プレイ約3分", en: "About 3 min a play" }, { ja: "マウスだけ", en: "Mouse only" }],
    crop: [.5, .5, .8],                         // 泡のアイコンに使うカバーの部分
    fx: "match"                                 // 泡が割れたときに飛ぶもの(下の説明)
  },
```

`fx` は、トップの水槽で泡が割れたときに飛び散るもの(`press` 新聞の切れ端 / `cloth` チェックの布 / `match` ハート / `frogbit` 浮き草 / `sealed` 警告の火花)。省略すると水しぶきだけになります。`crop` は泡のアイコンに使うカバー画像の部分(`[中心x, 中心y, 大きさ]`、画像に対する割合)。

これだけで、トップの水槽の泡・作品一覧と、全作品ページ下部の「ほかの作品」、作品ページの「遊ぶ」帯に自動で反映されます。

## 注目作(featured)の仕組み

`games.js` で `featured: { … }` を付けた作品は「注目作」になります(付けるのは1作だけ)。

- トップの水槽で、ひとまわり大きな泡に「NEW」を付けて、いちばん最初に浮かんでくる
- トップの作品一覧に「新作」マークが付く
- 全ページ上部のバー中央に「NEW」リンクが出る(注目作のページ自身では出ない)
- 各作品ページ下部の「ほかの作品」で、先頭に NEW バッジ付きで並ぶ

注目作を入れ替えるときは、今の作品から `featured` を外し、新しい作品に付けるだけです。
`featured` の中身(題字・見出し・箇条書き・ボタン文言)は Silent Press の例をコピーして書き換えてください。
外した作品は、ふつうの泡に戻ります。

## トップの水槽について

- 泡の中の丸いアイコンは、各作品の `cover` を `crop`(`[中心x, 中心y, 大きさ]`、画像に対する割合)で切り抜いて使います。文字が途中で切れるときは `crop` を調整してください(例:`[.5, .5, 1]` は中央を最大の大きさで)。
- カバー画像が読み込めないときは、index.html の `artOf()` でコードで描いた作品アイコンに自動で切り替わります。
- 泡の下の名前は `short`。作品をクリック(スマホはタップ)すると「つかまえて」作品カードが開きます。カードには `genre`・`title`(「和題(英題)」の形なら2段に分けて表示)・`tagline`・itch.io への「遊ぶ」ボタン・作品ページへのリンクが出ます。`buy` がある作品には「製品版」ボタンも出ます。
- `price` に「無料」(`{ ja: "無料", en: "Free" }`)と書いた作品は、ボタンが「無料で遊ぶ」になり、「無料・ブラウザで遊べる」のタグが付きます。`tags` には遊ぶ時間や操作などの目安を書くと、作品一覧とカードに並びます(例:`{ ja: "1プレイ約3分", en: "About 3 min a play" }`)。
- 注目作(`featured`)の項目:`play` 体験版ボタンの文言 / `playNote` その下の小さな一言 / `priceShort` 製品版ボタンに添える価格 / `demo` 体験版と製品版の違いの一行 / `bar` 上部バーの NEW の後ろの一言 / `points` 作品一覧に並ぶ特徴タグ。
- 泡が割れたときに飛ぶものは `fx`(`press` 新聞の切れ端 / `cloth` チェックの布 / `match` ハート / `frogbit` 浮き草 / `sealed` 警告の火花)。
- つかまえた作品の数は右下に表示され、そのブラウザに記憶されます。全部つかまえると泡が一斉に湧き、X への案内が出ます。
- 遊べること:作品をつかまえる/ドラッグして投げる/水面をなでて波を立てる/水中をクリックして泡を出す/水面に浮いた泡をなでて割る。
- パソコンやスマホで「アニメーションを減らす」設定がオンになっていても、水槽は動きます(サイトの主役のため)。動きが苦手な人は、水槽の左下の「動きを止める」ボタンで止められます。止めた状態はそのブラウザに記憶されます。
- スマホでは、水の部分をスワイプすると普通にスクロールします(作品に触れたときだけスクロールを止めます)。

### カバー画像・スクショのURLの取り方

itch.io の作品ページで画像を右クリック →「画像アドレスをコピー」。
カバー画像は作品ページの共有用画像(`og:image`)が `…/original/…` 形式のURLで使えます。

## 注意点

- **画像は itch.io のサーバーから直接読み込んでいます。** itch.io 側で画像を差し替えるとURLが変わり、サイトの画像が切れます。気になる場合は画像をダウンロードして `games/<スラッグ>/img/` に置き、`src` をそのファイル名に書き換えてください。
- フォントは Google Fonts から読み込んでいます。オフラインで開くと代わりのフォントで表示されます。
- 日本語/EN の切替は、`<span lang="ja">…</span><span lang="en">…</span>` の組で書いた部分が出し分けられます。片方しか書かない場合は `lang` を付けなければ両言語で表示されます。
- 各ページのヒーローにある小さなデモ(布めくり・スワイプ・浮き草すくい・水質ログ・写真の切り取り)は、サイト用の演出です。実際のゲームの仕様や計算式とは別物です。
